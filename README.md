# inhPhaton — Боги (Paper 26.2)

Серверный плагин персональной реальности: позволяет показывать или скрывать отдельные сущности, эффекты и фантомных мобов конкретному игроку, не затрагивая остальных.

## Структура
- src/main/java/ru/khozain/inhphaton — исходники
- src/main/resources/paper-plugin.yml — метаданные Paper
- config/config.yml — пример конфигурации
- docs/compat-layer.md — заметки по compat layer
- TZ_Gods_Paper_26_2.pdf — исходное ТЗ

## Текущее состояние
Исходная версия проекта загружена в Git перед функциональным рефакторингом. Известные ограничения исходной реализации: клиентский spawn/teleport/destroy фантомов оставался no-op, persistence после restart не реализован.

## Сборка
Для проекта добавлен Gradle Kotlin DSL. Для воспроизводимой сборки необходимо использовать Gradle Wrapper, который будет добавлен при следующем проходе.
